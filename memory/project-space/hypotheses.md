# Hypotheses — Hannah's Bread Company

Ranked candidate hypotheses for Phase 1. Each row maps to a branch in `issue-tree.md`. ICE scores reflect the value of validating the gap once Dynatrace instrumentation is live (greenfield context — all hypotheses are currently open pending implementation). The team updates Status as evidence arrives post-deployment.

## Status legend

- **open** — not yet investigated.
- **blocked: instrumentation** — hypothesis requires telemetry not yet deployed; named gap must be closed first.
- **validating** — investigation in progress; evidence is being gathered.
- **confirmed** — exit criteria met; this is a real cause.
- **ruled out** — exit criteria met; this is not the cause.
